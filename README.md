# OscGoesBuzz

A fork of [OscGoesBrrr](https://github.com/OscToys/OscGoesBrrr) that adds:

- **Lovense Game Mode**: drive Lovense toys straight through the Lovense Remote app (phone or PC) over your local network. No Intiface or Lovense Connect needed. Toys with more than one function (Vibrate + Rotate, Pump, Suction, dual motors…) show up as separate outputs you can link independently.
- **Battery & status**: live battery level, connection state and model for every Lovense toy, plus a one-click *Test* buzz.
- **Patterns**: Pulse, Wave, Heartbeat, Fireworks and Earthquake rhythms on any vibrate/rotate output (Lovense *or* Intiface). They follow your avatar's intensity. Lovense's own built-in presets are available per output too.
- **Intensity shaping** per output: min/max range (with a floor so light contact is still felt) and a response curve, with a live preview.
- **Safety**: a *Stop all* button, a system-wide stop hotkey that works while you're in VR (default `Ctrl + Shift + Space`), and a master intensity slider.

### Connecting Lovense

1. Pair your toys in **Lovense Remote**.
2. In the app open **Discover → Game Mode** and enable LAN.
3. In OscGoesBuzz, open **Lovense Game Mode** and type the *Local IP* shown in the app (and the port, if listed). Leave the IP empty if Lovense Remote for PC is running on the same computer.
